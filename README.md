# Prospect 1 – Grade 7 (Android app)
Standalone WebView app, Android 5.0+ (API 21+), all CPU types. The book is in app/src/main/assets/index.html.

Build the APK:
A) Android Studio: File > Open this folder > Build > Build APK(s). Output: app/build/outputs/apk/release/app-release.apk
B) Command line (JDK 17 + Android SDK): gradle assembleRelease
C) GitHub (nothing to install): upload this folder to a new repository, open Actions > "Build APK" > download artifact Prospect7-APK.
